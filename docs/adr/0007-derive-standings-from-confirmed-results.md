# Derive standings from confirmed results

The server will derive Standings from each Finished Match's current official Match Result and explicit Standing Adjustments instead of storing a separately editable table. When a Technical Result supersedes the Played Score, calculations use the Technical Result while preserving the Played Score in Match history. Admins may correct Match Results or record reasoned adjustments but may not directly edit calculated totals, preventing official results and standings from becoming inconsistent while retaining support for sanctions and technical decisions.
